## Design Context

### Users
Law-firm staff reviewing public breach notifications and assessing new or changed reports. Source evidence, count scope and freshness are essential. User accepted the review-queue proposal on September 5, 2026.

### Brand Personality
Restrained, precise, professional. Support confidence through visible evidence and honest uncertainty.

### Aesthetic Direction
Anthropic-inspired warm cream surfaces and charcoal text, bold sans-serif page titles, and selective serif evidence headings. Rounded controls (12 px) and panels (16 px), no decorative dots, and clear line icons for secondary actions. Keep meaningful source-health labels. Compact working table and persistent evidence pane; avoid large metric cards, decorative gradients, and noisy icons. Desktop first with complete mobile access. User accepted the layout, requested an established UI token pack, and selected this aesthetic on September 5, 2026. Use Open Props scales through frontend/src/styles/tokens.css, with the three-color brand extension in frontend/src/lib/theme.ts. See docs/design-tokens.md.

### Design Principles
- Put new and changed reports before aggregate statistics.
- Keep original evidence and field meaning visible.
- Distinguish failed collection from no new data.
- Preserve unknown counts and uncertain dates honestly.
- Show local/demo state explicitly; public assets contain no firm work.
