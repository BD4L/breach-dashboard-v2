## Design Context

### Users
Law-firm staff reviewing public breach notifications and assessing new or changed reports. Source evidence, count scope and freshness are essential. User accepted the review-queue proposal on September 5, 2026.

### Brand Personality
Restrained, precise, professional. Support confidence through visible evidence and honest uncertainty.

### Aesthetic Direction
Light neutral surfaces, dark ink, subtle teal accent, readable typography. Compact working table and persistent evidence pane; avoid large metric cards, decorative gradients, and noisy icons. Desktop first with complete mobile access. User accepted the layout and requested an established UI token pack; use Open Props through the semantic roles in frontend/src/styles/tokens.css. See docs/design-tokens.md.

### Design Principles
- Put new and changed reports before aggregate statistics.
- Keep original evidence and field meaning visible.
- Distinguish failed collection from no new data.
- Preserve unknown counts and uncertain dates honestly.
- Show local/demo state explicitly; public assets contain no firm work.
